# InsurePool

Decentralized insurance coverage pools.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/InsurePool.sol`
- Stacks: `contracts/stacks/contracts/insurepool.clar`

## Setup
```bash
pnpm install
pnpm dev
```
